How a new app is added

  1. Add a versioned table and seed records. Set role permissions and audit scope, and add a demo account when the module has its own role.
  2. Create a router with permission-checked reads and mutations through run_command. Register the router and ModuleSpec.
  3. Add templates and forms, then test allowed actions, denied roles, reasons, stale versions, and any import or export behavior.
